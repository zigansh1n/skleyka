# Migrating to OpenSceneSense 1.2

Existing `VideoAnalyzer`, `OpenRouterAnalyzer`, model configuration, prompt configuration, frame selectors, imports, and `analyze_video()` calls remain supported.

## Prefer structured results

```python
result = analyzer.analyze_video_structured("video.mp4")
print(result.summary.brief)
```

Keep `analyze_video()` when a consumer expects the original dictionary keys.

## Endpoint behavior

OpenAI uses the Responses API by default. Set `api_mode="chat_completions"` only for a compatible endpoint that does not implement Responses. `auto` does not reinterpret authentication, rate-limit, or model failures as endpoint incompatibility.

## Audio

The built-in API transcriber now relies exclusively on FFmpeg. Install FFmpeg and FFprobe on the host. To bypass audio, set `enable_audio=False`; to replace it, pass an object implementing `transcribe(video_path)`.

## Library logging

The library no longer calls `logging.basicConfig()`. Applications and the CLI own handler and formatting configuration.

## Result validation

The schema is available through `analysis_result_schema()`, `openscenesense schema`, and `Docs/analysis_result.schema.json`.
