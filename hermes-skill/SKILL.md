# Разбор монтажа

Готовый CLI: `/home/hermes/.local/bin/video-montage`.
Исходники: `/home/hermes/ai-tools/video-montage-analyzer`.
Рабочие папки: `/home/hermes/downloads/video-montage/`.
Все вычисления и загрузки выполняй на сервере.

## Обычный запуск

Получи видеофайл через доступное скачивание вложений или серверный `yt-dlp`.
Для YouTube предпочтителен H.264; AV1 поддерживается через проверяемый FFmpeg-прокси.
Если пользователь указал участок, вырежи его на сервере без изменения частоты кадров
и передай его начало через `--source-offset`. Транскрипт в `--transcript` должен использовать
ту же глобальную шкалу времени. `--transcribe` сам учитывает смещение.
Если участок не указан, анализируй предоставленный референс целиком в пределах лимитов.

Используй режим **precision**: он сохраняет все кадры с реальными PTS, включая VFR,
и сам выполняет до 800 параллельных запросов, независимые проверки границ и адресные
повторы при пропусках/разногласиях. Кадры нарезаются параллельно, и анализ начинается,
пока остальная часть ролика ещё готовится. Указывать FPS не нужно. Не интерполируй 25 fps до 60.

```bash
/home/hermes/.local/bin/video-montage precision /absolute/video.mp4 \
  -o /home/hermes/downloads/video-montage/unique-run --transcribe
```

Для видео без речи убери `--transcribe`; для готовых субтитров передай
`--transcript /absolute/transcript.json`. Долгий запуск выполняй через серверный
`terminal(background=true, notify=true)` и дождись завершения.
Сначала оценить объём без платных запросов можно тем же вызовом с `--prepare-only`.

По умолчанию: все кадры, 320 пикселей по длинной стороне, 48 основных + до 8 соседних
кадров с каждой стороны на запрос, 800 одновременных запросов. На эталоне из 76 склеек
320 и 640 пикселей дали одинаковую точность (F1 0.99), 320 — в 2,3 раза меньше токенов.
Для мелких надписей подними `--frame-size` до 640 или выше. Новые настройки подготовки
требуют новой выходной папки.

## Модель и разрешения

По умолчанию **Kimi K3** через DashScope (`kimi-k3`, Chat Completions,
`https://dashscope.aliyuncs.com/compatible-mode/v1`), reasoning `none`: рассуждение
выключено, на склейках оно не повышает точность и замедляет в 2,5–3 раза.
Kimi K3 не принимает видео напрямую, поэтому плагин передаёт кадры изображениями.
Ключ — только в `/home/hermes/.config/video-montage/config.env` с правами 0600.
Не печатай конфигурацию и не используй основные ключи Hermes/Codex/Anthropic.
`video-montage doctor` безопасно показывает модель и наличие настроек.

Luna уже разрешена пользователем для текущей квалификации инструмента. Для будущего
запуска через явно выбранную пользователем Luna используй только локальное переопределение:

```bash
MONTAGE_ALLOWED_MODELS=gpt-5.6-luna \
  /home/hermes/.local/bin/video-montage precision /absolute/video.mp4 \
  -o /home/hermes/downloads/video-montage/unique-luna-run \
  --model gpt-5.6-luna --transcribe
```

Это не меняет Kimi K3 по умолчанию. Автоматически переключать модели после ошибки нельзя.
Anthropic для этого инструмента запрещён. HTTP 503 означает ошибку провайдера,
а не отсутствие монтажа. После исчерпания встроенных повторов не запускай бесконечный цикл.

## Проверка и выдача результата

Прочитай `result.json` и `report.md`:

- `status=complete`, `analyzed_frames=source_frames`, `completed_windows=total_windows`:
  все окна разобраны. Это не доказательство безошибочности модели.
- `quality_status=reviewed`: каждая кандидатная граница получила два согласующихся
  вердикта. Резкая склейка и скачок кадрирования считаются одной семьёй резких изменений;
  точные варианты сохранены в `classification_alternatives`.
- `quality_status=needs_review`: покажи спорные таймкоды из `unresolved_candidates`
  и сравни их кадры. Не выдавай спорный переход за установленный факт.
- `status=partial`: сообщи причину из `failures`; повтор той же команды продолжает
  сохранённую работу. Код выхода 0 — завершено с согласованными границами;
  2 — обработка завершена, остались спорные границы; 1 — частичный результат/ошибка.

Лимиты: 300 попыток API и 20 млн учтённых/зарезервированных токенов **суммарно по папке**,
включая возобновления. Повышай `--max-calls`/`--max-tokens` только в пределах порученного
пользователем объёма. Лимит токенов — локальный резерв, не гарантированный денежный потолок
провайдера. Неизвестный расход после обрыва учитывается отдельно, а не как ноль.

Дай монтажную схему с таймкодами и действиями для повторения. `montage.csv` — монтажный
лист, `shots.csv` — длительности планов, `report.md` — полный текст. Для просмотра кадров открой `report.html` вместе с
соседней папкой `frames/`. Для передачи упакуй HTML и кадры либо отправь текст через
`MEDIA:/absolute/path/report.md`. В отчёте всегда называй фактически использованную модель.

## Границы метода

- Все исходные кадры передаются как JPEG; модель может неверно истолковать их даже
  после двух проверок. Кандидаты детектора не равны истинным склейкам.
- Границы проходят независимые проверки, события внутри планов остаются наблюдениями
  основного прохода. Их нельзя называть вручную подтверждёнными.
- Обработка картинок не слышит музыку/SFX. Локальный Whisper даёт только речь.
  Для анализа звука нужен отдельно выбранный аудиомодельный маршрут.
- Способы повторения — рекомендации по видимому результату, не исходный проект редактора.
  Точный плагин, объектив, параметры и скрытые слои по видео не установлены.
